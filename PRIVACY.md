# PrepPush Privacy Policy

**Last updated:** May 26, 2026

PrepPush (“the extension”) is a browser extension that helps you save accepted HackerRank solutions to your own GitHub repository with optional AI-generated study notes.

## Summary

- **We do not run a backend server** for PrepPush. The extension runs in your browser.
- **We do not collect or store your data on our servers** — there are no PrepPush-owned servers in this project.
- **You choose** whether to connect GitHub and Google Gemini by entering API keys in the extension settings.

## What data the extension accesses

| Data | Where it goes | Why |
|------|----------------|-----|
| HackerRank submission details (problem name, language, status, code, timestamps) | Your browser → optional GitHub repo | Core feature |
| GitHub personal access token | Chrome `storage.sync` (local to your browser profile) | Push files to your repo |
| Gemini API key | Chrome `storage.sync` (local to your browser profile) | Optional AI analysis |
| Latest submission / push status | Chrome `storage.local` | Popup display |

## What leaves your device

Data is sent **only** when you configure credentials and use the extension:

1. **GitHub** (`api.github.com`) — to create/update files in **your** repository using **your** token.
2. **Google Gemini** (`generativelanguage.googleapis.com`) — when you save a Gemini key and submit an accepted solution (or run **Test AI**). Request content includes problem context and your solution code for analysis.
3. **HackerRank** (`hackerrank.com`) — the extension reads challenge metadata from HackerRank’s public REST endpoints to fill difficulty/subdomain fields.

PrepPush does not send data to any other third parties.

## API keys and security

- Tokens and API keys are stored using **Chrome extension storage** on your device, not by PrepPush developers.
- Anyone with access to your computer or Chrome profile could read stored keys — treat your machine as trusted.
- Use a **classic GitHub PAT** scoped to **repo** only, and revoke it anytime from GitHub settings.
- Gemini free-tier keys are subject to [Google’s terms and privacy policy](https://policies.google.com/privacy).

## AI-generated content

Analysis (time/space complexity, trick) is generated by Google Gemini and may be inaccurate. You are responsible for reviewing content before relying on it for interviews or study.

## Children

PrepPush is not directed at children under 13.

## Changes

This policy may be updated in the repository. For a published Chrome Web Store build, the policy URL should point to the latest version of this file in your public repo.
